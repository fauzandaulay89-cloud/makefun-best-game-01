LUMEN HARVEST — an original neon arcade game: pilot a harvester ship, collect lumen, blast void shards through 10 escalating waves, and destroy the Hollow Star boss to win. Keyboard + mouse, offline static files, WebAudio synth sound, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click or press Enter to launch, WASD/arrows to fly, mouse to aim, hold click or Space to fire, E for NOVA, P to pause, R to restart.
